Deployment Checklist

  1. Paste the generated .env content into your local .env file.
  2. Paste the generated filters: content into your config.yaml file.
  3. Paste the generated companies: list into your companies.yaml file.
  4. In .github/workflows/daily.yml, replace the - cron: line with the generated line.
  5. In your GitHub repo (Settings → Secrets and variables → Actions), add these Secrets: GEMINI_API_KEY, SMTP_USER, SMTP_PASS, MAIL_TO, and PROFILE_JSON.
  6. This is what makes GitHub Actions run your daily job search automatically on schedule. Nothing on this page sends an email or talks to any API.
